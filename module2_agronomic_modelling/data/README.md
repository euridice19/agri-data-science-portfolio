# Data — Module 2

## weather_maize_po_valley_2024.csv

Daily meteorological data for a point near Cremona in the Po Valley,
covering the 2024 maize growing season (late April to late August, 123 days).
Exact coordinates are set in `notebooks/water_balance_maize_fao56.ipynb`.

Variables: daily maximum, minimum and mean air temperature at 2 m, mean
relative humidity at 2 m, wind speed at 10 m, shortwave radiation sum,
and precipitation sum.

Source: Open-Meteo (https://open-meteo.com), licensed under CC BY 4.0.
Weather data by Open-Meteo.com.

The notebook downloads this data from the Open-Meteo API, so the file can be
regenerated by re-running it. The copy here is kept so the analysis runs
without network access.
