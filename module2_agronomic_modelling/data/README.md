# Data — Module 2

## weather_maize_po_valley_2024.csv

Daily meteorological data for a point near Cremona in the Po Valley
(45.13 N, 10.02 E), covering the 2024 maize growing season
(25 April to 25 August, 123 days).

Variables: daily maximum, minimum and mean air temperature at 2 m, mean
relative humidity at 2 m, daily mean wind speed at 10 m (m/s, computed
from hourly values), shortwave radiation sum, and precipitation sum.

Source: Open-Meteo Historical Weather API (https://open-meteo.com),
licensed under CC BY 4.0. Weather data by Open-Meteo.com.

The notebook downloads this data directly from the Open-Meteo API, so the
file can be regenerated by re-running it. The copy here is kept so the
analysis can be inspected without network access. The Open-Meteo reference
ET₀ used for validation is included in `outputs/water_balance_results_2024.csv`.
