# Data — Module 1

No data files are committed to this repository. This page explains how to
obtain or regenerate everything the notebooks expect.

## Synthetic soil moisture series

Generated by `notebooks/01_data_generation.ipynb`. The notebook uses a fixed
random seed (42), so re-running it reproduces the exact series used in
`02_iot_soil_moisture_interpolation.ipynb`, including the artificial sensor
outages. Run notebook 01 before notebook 02.

## Kaggle IoT Agriculture 2024

Real greenhouse sensor data (13 features, 37,923 rows) collected at Tikrit
University, Iraq, as part of the MSc research of Mohammed Ismail Lifta,
supervised by Assistant Professor Wissam Dawood Abdullah.

Source: https://www.kaggle.com/datasets/wisam1985/iot-agriculture-2024

**Licence: CC BY-ND.** The terms require attribution and prohibit
distributing modified versions of the dataset. For that reason neither the
raw file nor the cleaned version produced in
`03_kaggle_real_data_exploration.ipynb` is published here — only the analysis
is. The cleaning steps in that notebook reproduce the cleaned dataset from
the original download.

To run notebook 03:

1. Download the dataset from the Kaggle page above (a free account is needed).
2. Unzip it and place the CSV at `data/raw/iot_agriculture_2024_raw.csv`.
3. Watch for a double extension (`.csv.csv`) if you rename the file on
   Windows with file extensions hidden.

Known quirks in the raw file, handled in notebook 03: the column name
`tempreature` is misspelled at source, timestamps are not in chronological
order, and the N/P/K columns are uniformly 255, which appears to be a sensor
placeholder rather than a measurement.
